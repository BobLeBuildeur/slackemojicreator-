# Documentation

Project documentation lives in this folder.

## Conventions

- Every document filename is prefixed with the ISO date: `YYYY-MM-DD-title.md`
- Subfolders:
  - `prd/` — product requirement documents for new features
  - `plans/` — implementation plans written from PRDs before coding
  - `design/` — design system, tokens, and UI guidance

Agents must follow the Cursor rules in `.cursor/rules/` for PRDs, plans, docs naming, and UI constraints.
